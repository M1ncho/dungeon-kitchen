# 기본 조리법 강화 — 재계산 결과 (추천안 + 장인 도구 전부 2단계)

상태: **구현 전, 확인 대기**. 코드·DB는 바뀌지 않았다. 초안은 `docs/basic-tools-draft.md`.

## 계산 조건

- 기본 조리법: 확정 추천안
  - 2회째 효과 ×0.33, 끓이기 2회째는 독성 감소 없음
  - 2단계 크기: 이동량 ×0.8 / 1.0 / 1.2, 끓이기 당김 12 / 15 / 18%
  - 튀김 냄비 "약" → 독성 증가 없음, 절임 독 숙성 −30% (난이도에는 영향 없음)
- 장인 도구(발효·훈연·갈기·찌기): 각 2단계, 1단계 규칙(2회 사용)에도 "2회째 ×0.33"을 같게 적용
  - 확대: 2회째 배율 증가분 ×0.33 / 회전: 2회째 각도 ×0.33 / 찌기: 2회째 비율 ×0.33 / 갈기: 2회째도 반전·독성 0 유지
  - 2회째 독성 변화(발효 +1, 훈연·찌기 −1)는 그대로 유지한 것을 기본으로 계산
- 층마다 해금된 도구만 포함 (1층: 없음, 3층: 발효·훈연, 5층: 전부)
- 재료는 그 층까지 해금된 것에서 무작위 2~4개, 조리법은 한 요리에 총 4회까지

## 1. 최적 플레이 (지정한 기준) — 완벽(★3) %

| 시나리오 | 1층 | 3층 | 5층 |
|---|---|---|---|
| 기준 (기본 0단계 + 가진 도구 0단계) | 46.2 | 87.2 | 99.6 |
| 기본 2단계(추천안)만 | 70.6 | 92.8 | 100 |
| 도구 2단계만 | 46.2 | 93.0 | 99.6 |
| **전부 2단계** | **70.6** | **94.8** | **100** |
| 전부 2단계, 도구 2회째 독성 변화 없음 | 70.6 | 93.8 | 100 |

- **5층이 85%를 넘는다** → 지정한 규칙에 따라 구현 전에 멈췄다.
- 다만 이 기준은 5층에서 **이미 포화**됐다. 아무것도 강화하지 않은 도구 8개만으로 완벽의 99.6%에 닿으므로, 85% 기준으로는 강화의 영향을 가를 수 없다.
- 지난 초안의 5층 기준값(52.7%)에는 장인 도구가 빠져 있었다. 도구 4개가 들어가면서 이 지표가 포화된 것이다.

## 2. 더 현실적인 기준 — 같은 재료 조합으로 무작위 계획을 K번 시도해 가장 좋은 결과

완벽 %, 조합 6,000개.

| 시도 횟수 | 시나리오 | 1층 | 3층 | 5층 |
|---|---|---|---|---|
| 10번 | 기준 | 31.6 | 43.4 | 45.1 |
| 10번 | 기본 2단계만 | 32.5 | 44.1 | 48.0 |
| 10번 | **전부 2단계** | 32.5 | 42.4 | **50.3** |
| 30번 | 기준 | 41.9 | 64.2 | 73.9 |
| 30번 | 기본 2단계만 | 49.2 | 68.8 | 77.1 |
| 30번 | **전부 2단계** | 49.2 | 68.9 | **83.1** |

- 이 기준에서는 5층이 85%를 넘지 않고, 기준 대비 **+5~9%p**다.

## 3. 무작위 계획 1번 (300,000회) — 완벽 %

| 시나리오 | 1층 | 3층 | 5층 |
|---|---|---|---|
| 기준 | 6.29 | 6.84 | 6.90 |
| 기본 2단계만 | 5.87 | 6.91 | 7.11 |
| 도구 2단계만 | 6.29 | 6.42 | 7.13 |
| **전부 2단계** | 5.87 | 6.51 | 7.32 |
| 전부 1단계(2회, ×0.33) | 5.71 | 6.48 | 7.26 |

- 5층 완벽률이 6.90% → 7.32%(+0.4%p)로 거의 그대로다. 2회째 ×0.33은 확실히 약하다.
- 1층은 추천안에서 오히려 소폭 낮아진다. 2회째의 약한 이동이 무작위로 쓰일 때는 방해가 되기 때문이다.

## 4. 장인 도구 1단계에 같은 규칙을 적용할 때 다르게 볼 점

- **독성 변화**: 훈연·찌기의 −1과 발효의 +1이 2회째에도 그대로인지 정해야 한다. 끓이기만 "2회째 독성 감소 없음"으로 지정돼 있다. 없앤 경우와의 차이는 1%p 안팎이라 **그대로 두는 안**으로 간다.
- **갈기**: 2단계는 한 번에 재료 2개를 반전하고 독성을 0으로 만든다. 2회째도 유지하면 첫 재료 뒤에 쓸 경우 최대 3개 재료가 영향을 받아, 4층 이후 독성 제한이 사실상 약해질 수 있다. **갈기 2회를 합쳐 영향받는 재료는 최대 2개**로 두는 안을 제안한다 (시뮬레이션에는 이 상한이 없어서 반영하지 못했다).
- **그 외**: 회전 2회째 각도 ×0.33(30° → 약 10°), 확대 증가분 ×0.33(1.3배 → 약 1.1배), 찌기 2회째 비율 ×0.33(20% → 약 6.6%). 다르게 할 이유는 없다.

## 5. 결론과 판단 요청

- **추천: 그대로 구현.** 현실적인 기준으로 기준 대비 +5~9%p는 지난번 도구 때(×2 이상)보다 훨씬 얌전하고, 지나치게 쉬워질 위험이 낮다. 더 낮추고 싶으면 크기 선택 폭을 ×0.9/1.0/1.1로 줄이는 안이 있다.
- 결정할 것: (1) 그대로 구현할지, (2) 갈기 영향 재료 상한(최대 2개)을 둘지.
- 확인되면 구현할 것: 고니 소개 "고블린 화덕지기 할머니", CLAUDE.md "요리사 능력치 설계 시 불 감각은 도구 강화와 겹치지 않는 효과로" 메모.

# 화구 3칸 재계산 (구현 시 확정)

결정: 기본 조리법 강화는 추천안 그대로, 갈기는 2회를 합쳐 영향 재료 최대 2개, 장인 도구 2회째 독성 변화는 그대로, 조리법은 종류 무관 **총 3번(화구 3칸, 고정)**.
조건: 위와 같고 한 요리의 조리법 총 횟수만 3으로 제한, 갈기 합산 상한 2 적용. 층마다 해금된 도구만 포함.

## 완벽(★3) %

| 지표 | 시나리오 | 1층 | 3층 | 5층 |
|---|---|---|---|---|
| 최적 플레이 | 기준(기본 0단계 + 가진 도구 0단계) | 47.9 | 83.2 | 97.8 |
| 최적 플레이 | 기본 2단계(추천안)만 | 67.7 | 89.9 | 98.9 |
| 최적 플레이 | 도구 2단계만 | 47.9 | 89.9 | 98.9 |
| 최적 플레이 | **전부 2단계** | **67.7** | **93.1** | **99.7** |
| 30번 시도 | 기준 | 42.2 | 62.8 | 69.3 |
| 30번 시도 | 기본 2단계만 | 47.8 | 66.4 | 67.4 |
| 30번 시도 | **전부 2단계** | **47.8** | **64.3** | **69.6** |
| 10번 시도 | 기준 | 32.4 | 41.0 | 42.2 |
| 10번 시도 | **전부 2단계** | 35.4 | 41.5 | 41.9 |
| 무작위 1번 | 기준 | 6.23 | 6.76 | 6.58 |
| 무작위 1번 | **전부 2단계** | 6.64 | 6.79 | 6.49 |

- **화구 3칸은 최적 플레이 지표를 낮추지 못한다.** 도구 8개가 있는 5층은 총 3번으로 제한해도 기준이 이미 97.8%다 (4번 제한일 때 99.6%). 화구 3칸의 효과는 "한 요리에 조리법을 몰아 쓰기"를 막는 데 있고, 이 지표로는 보이지 않는다.
- **강화의 효과는 약하다.** 같은 재료로 30번 시도한 지표로 기준 대비 완벽 비율은 1층 +5.6%p, 3층 +1.5%p, 5층 +0.3%p다. 무작위 1번 지표는 거의 같다. 2회째 ×0.33과 화구 3칸이 합쳐져 강화가 "쉬워짐"보다 "선택지가 늘어남"에 가깝다.
- 지나치게 쉬워질 위험은 낮다. 강화가 약하다고 느껴지면 `secondUseBp`(3300)나 크기 선택 폭을 키운다 (화구 칸 수는 고정).
