# 기본 조리법 강화 (1층 장인) — 초안과 균형 점검

상태: **초안 (구현 전, 확인 대기)**. 코드·DB는 바뀌지 않았다.
요청: 기본 조리법 4개(굽기·끓이기·튀기기·절이기)도 새 조리 도구처럼 강화할 수 있게 한다. 기존 장인·도구·강화 구조를 재사용하고 배포 이후 개발 규칙을 지킨다.

## 1. 1층 장인 초안

| | |
|---|---|
| 이름 | **고니** — 이끼 낀 입구의 고블린 화덕지기 할멈 |
| 말투 | 푸근한 할머니 말투 ("~란다 / ~렴 / ~구나") |
| 겹침 확인 | 바르둔(하게체), 몰루(들뜬 반말), 투르간(퉁명), 세린(조용한 존댓말), 온유(하오체)와 다르다 |

- **등장**: 부탁이 없고 처음부터 공방이 열려 있다. 기본 도구는 모든 유저가 이미 가진 것으로 처리하고, 고니는 강화만 담당한다.
- **인사**: "어서 오렴, 입구까지 잘 왔구나. 화덕이며 솥이며 다 내가 오래 길들인 것들이란다."
- **평소**: "불은 거짓말을 안 한단다. 정성 들인 만큼 돌려주지."
- **1단계 강화**: "한 번 더 쓸 수 있게 손봐 주었단다. 같은 요리에 두 번까지 쓰렴."
- **2단계 강화**: 도구마다 다른 대사. 화덕·솥·튀김 냄비는 "약하게 / 보통 / 세게 고르렴", 절임 독은 "숙성이 좀 빨라졌단다".

| 기본 도구 | 조리법 |
|---|---|
| 화덕 | 굽기 |
| 무쇠 솥 | 끓이기 |
| 튀김 냄비 | 튀기기 |
| 절임 독 | 절이기 |

## 2. 강화 규칙

- 1단계: 요리 하나에 해당 조리법 2회 사용
- 2단계: 사용할 때마다 효과 크기 약·보통·강 선택
  - 굽기·튀기기·절이기: 이동량 약 ×0.67 / 보통 ×1.0 / 강 ×1.33
  - 끓이기: 중심 당김 10 / 15 / 20%, 독성 감소 −2 / −3 / −4
- 2단계 개성: 절임 독은 숙성 시간 −30%(600초 → 420초), 튀김 냄비는 "약"으로 튀기면 독성 증가 없음

## 3. 강화 비용 (플레이 후 조정 예정)

1단계는 1~2층 재료, 2단계는 3층 이상 재료를 쓴다.

| 도구 | 1단계 | 2단계 |
|---|---|---|
| 화덕 | 150G + 고블린 고기×3 + 동굴 버섯×2 | 500G + 숯불 열매×3 + 용암 소금×2 |
| 무쇠 솥 | 300G + 쓴맛 독버섯×2 + 이끼 젤리×3 | 900G + 마그마 게×1 + 서리 허브×3 |
| 튀김 냄비 | 180G + 박쥐 날개×3 + 그을린 육포×2 | 600G + 화염 뿌리×3 + 도롱뇽 꼬리×2 |
| 절임 독 | 180G + 슬라임 젤리×3 + 이끼 젤리×2 | 600G + 불씨 꿀×1 + 발광 열매×3 |

- 1단계 합계 810G, 2단계 합계 2,500G. 끓이기가 가장 강해서 가장 비싸게 잡았다.

## 4. 균형 점검

- **방법**: 층별로 재료 2~4개를 무작위로 뽑은 1,500조합. 조리법은 어느 위치에든 쓸 수 있고 한 요리에 최대 4회까지 쓴다고 가정하고, 그 조합에서 플레이어가 최선으로 만들었을 때의 최고 품질을 봤다.
- **한계**: 장인 도구(발효·훈연·갈기·찌기)는 뺐고, 실제 플레이어는 가진 재료로 제한된다. 절대값보다 기준과의 차이로 본다.
- **구역별 완벽 칸 수는 지표로 쓸 수 없었다**: 기준 상태에서 이미 구역마다 완벽 범위의 거의 모든 칸에 닿아서 강화해도 1,736 → 1,804로 거의 안 변한다. 강화의 효과는 닿는 칸이 아니라 "닿기 쉬워지는 것"에 있다.

### 완벽(★3) 비율, 최적 플레이 (%)

| 시나리오 | 1층 | 3층 | 5층 |
|---|---|---|---|
| 기준(현재) | 46.5 | 58.5 | 52.7 |
| 끓이기 2단계만 | 80.7 | 78.5 | 68.4 |
| 굽기 2단계만 | 49.9 | 70.4 | 68.3 |
| 튀기기 2단계만 | 49.7 | 73.7 | 77.1 |
| 절이기 2단계만 | 50.9 | 69.1 | 68.7 |
| 전부 1단계 | 77.5 | 87.7 | 87.5 |
| **전부 2단계(요청 그대로)** | **88.5** | **96.1** | **98.5** |

### 결과 요약

- **너무 쉬워진다.** 4개를 모두 강화하면 어느 층에서나 최적 플레이의 96% 안팎이 완벽이다. 1단계(2회 사용)만으로 이미 +30~40%p이고, 2단계의 크기 선택이 +8~10%p를 더한다.
- **끓이기가 가장 크다.** 끓이기 2회는 독성 −6이라 독성 규칙이 사실상 사라진다. 1층에서 완성 가능한 조합이 68.9% → 90.9%(1단계)로 늘어, 독성 때문에 막히던 31% 중 대부분이 풀린다.
- 굽기·튀기기·절이기는 개별로는 +3~25%p 정도이고, 합쳐지면서 급격히 커진다.

## 5. 조정안

전부 2단계 기준 완벽 비율.

| 조정 | 5층 | 1층 |
|---|---|---|
| 요청 그대로 | 98.5 | 88.5 |
| 2회째 효과 ×0.5, 끓이기 2회째 독성 −1 | 89.3 | 76.0 |
| **추천: 2회째 효과 ×0.33, 끓이기 2회째 독성 감소 없음(1회분만), 2단계 크기 ×0.8/1.0/1.2·당김 12/15/18%** | **77.9** | **69.0** |
| 요리당 추가 사용을 1회로 제한 | 96.4 | 86.5 |

- 추천안은 기준 대비 약 +22~25%p로, 지난번 찌기를 ×2에서 20%로 낮춘 기준과 비슷하다. 3층은 81.9%.
- 추가 사용 횟수 제한은 효과가 거의 없다. 최적 플레이어는 어차피 한 번만 추가로 써서 지금 점수를 만든다.
- 추천안의 끓이기 2회째는 "중심 당김 ×0.33, 독성 감소 없음"이다. "독성 감소는 1회분만"과 같은 방향.
- 크기 선택은 "약 ×0.8 / 강 ×1.2"로 줄이는 안이다. 원래 요청의 ×0.67/×1.33은 2회째 ×0.5 행까지만 확인했고, 추천안과는 크기를 바꿔서 따로 비교하지 못했다.
- 개성 효과(튀김 냄비 약 → 독성 없음, 절임 독 숙성 −30%)는 초안대로. 시뮬레이션에 포함했고 영향은 작다.

## 6. 구현 시 구조 (참고)

- 장인 하나가 도구 하나만 가지는 구조라서, 도구를 별도 테이블(`artisan_tools`)로 빼고 기존 장인은 도구 1개로 옮긴다.
- 도구 단계는 `user_artisans.tool_level` 하나뿐이라, 조리법별 단계 테이블을 추가하고 기존 값은 마이그레이션에서 백필한다.
- 기본 도구는 행이 없으면 0단계로 간주한다. 기존 계정의 동작은 그대로다.
- 새 컬럼은 모두 추가 방식이고 기존 컬럼은 지우지 않는다. 부탁 컬럼(`request_*`)만 NOT NULL을 풀어야 한다.
- 엔진: shift 유형에 크기 배율, 끓이기 크기별 독성, 튀기기 "약" 무독성, 절이기 숙성 −30%, 2회째 효과 배율을 추가한다. 0단계는 지금과 같게 유지한다.
- production에는 마이그레이션 → 시드 → 푸시 순서로 반영한다.
- 화면: 주방 조리법 버튼에 강화 단계 점(●○), 1층 장인 공방은 기존 장인 화면을 재사용해 기본 도구 4개를 카드로 나열한다.
- CLAUDE.md의 "불 감각" 메모는 현재 파일에 없다. 구현할 때 "요리사 능력치 설계 시 도구 강화와 겹치지 않는 다른 효과로" 메모를 새로 추가한다.

## 7. 열린 질문

**1층에 가게가 없어도 고니의 공방을 열어 둘까?**

- 추천은 **고니만 언제든 방문 가능**. 기본 조리법 강화가 필수적인 성장 경로라, 5층까지 내려간 유저가 강화하려고 1층으로 돌아가야 하면 불편하다.
- 접근은 홈 알림 카드와 주방의 조리법 칸에서 한다.
- 다른 장인까지 "가 본 층은 언제든 방문"으로 넓힐 수도 있지만 이번 범위를 넘어서 제안만 한다.

확인이 필요한 결정: (1) 조정안 선택(추천안 / 다른 값 / 요청 그대로), (2) 공방 접근 방식.
